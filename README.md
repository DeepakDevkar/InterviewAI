## Core Features

1. **Resume Analyzer Engine**: Parse CV documents (PDF/DOCX) using custom matching algorithms to score missing technology keywords and assign ATS scores.
2. **AI Question Generator**: Creates technical, behavioral, Coding and MCQ questions customized for specific target companies and roles using Google Gemini models.
3. **Interactive Mock Interview Room**: Connect HTML5 speech-to-text dictation, camera previews, question navigators, and timer controllers.
4. **Answer Evaluators Dashboard**: Grader analytics detailing Communication, Technical, Grammar and Confidence scores with side-by-side rewritten exemplar answers.
5. **Coding Playground**: algorithms workspace supporting JS, Python, C++ and Java compiles sandbox simulation, histories logs and global user leaderboards.
6. **Real-time WebSockets & Alerts**: Live notifications, typing indicators, online user count feeds, and status updates via Socket.io.
7. **Subscription Tiers Limits**: Enforce plan quotas (Free tier caps vs Pro/Enterprise unlimited access) integrated with simulated payments checkout.

## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (Local instance or Atlas URI)

### Installation

1. **Clone the Repository**
2. **Configure Environment Variables** (Refer to `deployment_guide.md` or `.env.example`)
3. **Run Backend Service**
   ```bash
   cd backend
   npm install
   npm start
   ```
4. **Run Frontend Application**
   ```bash
   cd frontend
   npm install --legacy-peer-deps
   npm run dev
   ```
